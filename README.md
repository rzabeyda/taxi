# Taxi Tallinn — Telegram Mini App

Клиент ставит маршрут и цену, водители получают уведомление в боте, первый принявший получает заказ.
Комиссия 10% (мин. 0,5 €), при долге 10 € водитель блокируется до оплаты.

- `server/` — FastAPI + aiogram (один процесс), SQLite
- `web/` — мини-апп (чёрная тема, мобильная)
- `deploy/taxi.service` — systemd, порт 8050 за nginx

Бот: /id — свой Telegram ID, /admin — статистика, /pay <id> <сумма> — записать оплату.
